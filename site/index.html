Understand the method

The method builds a picture from simple yes-or-no results. Difficult internal names appear only at the end of this section for traceability.

Middle gap

The estimated gap where Interaction and No interaction are each about equally likely.

Overall variation

How quickly or gradually the outcome changes around the middle.

Probability

The fitted curve’s estimated chance of an outcome at one chosen gap.

Confidence

How strongly the completed evidence supports an estimated value.

Probability is not confidence.

“99% chance of Interaction” describes the predicted outcome at a gap. “95% confidence range” describes uncertainty in an estimated answer. They are different statements.

How the next gap is chosen

Early search

The first requests move outward until both outcomes have been seen.

Narrow the change

The next requests concentrate between the two kinds of outcome. The physical gap step prevents meaningless tiny changes.

Improve the curve

The program chooses useful gaps that improve the middle and variation estimates.

What do Stage 1, Stage 2, MLE, and D-optimal mean?

Stage 1 is the early outward search. Stage 2 narrows the area where the outcome changes. MLE is the calculation that finds the middle and overall variation most consistent with all results. D-optimal is the internal rule for choosing a useful next gap after both outcomes are available.

Why can the same gap be requested again?

A repeat may be useful when a fresh independent article at that gap adds information. The app first looks for the nearest different reachable and useful setting.

Operate V1.14

Use this as the step-by-step operating manual. The default route is designed for a first study where the overall variation is not known.

Every starting entry, in plain language

First study - variation unknown
Use this default when you have no trustworthy earlier estimate. The program selects an internal starting search size; it does not report that starting value as a result.
Advanced - starting variation known
Use only when earlier evidence provides a reasonable starting value. This affects early requests but does not force the final answer.
Low middle-gap guess
Your smallest reasonable starting location for the 50/50 change. It is not the minimum gap limit.
High middle-gap guess
Your largest reasonable starting location for the 50/50 change. It is not the maximum gap limit.
Maximum tests
The most new articles this run may consume. It is a limit, not a promise that a curve or chosen confidence will be achieved.
Minimum permitted gap
The smallest physical gap the app is allowed to request.
Maximum permitted gap
The largest useful physical gap the app is allowed to request.
Regular gap step
Choose only if every multiple of the step can genuinely be built throughout the permitted range.
Confirmed gap list
Use a specific list of measured, buildable gaps. The app requests only values from that list.
Foil thickness
Construction information only. It does not decide the usable gap step and does not change the calculation.

What to do for every requested gap

  1. Read the build request

    The requested gap is shown with two decimal places, such as 2.50 mm.

  2. Build a new setup

    Use a fresh article and fresh spacer arrangement. Do not reuse a consumed setup.

  3. Take one measurement

    Measure the completed setup once. This one measured gap reading is used by the calculation.

  4. Enter the measured gap

    If the request was 2.45 mm but the setup measures 2.50 mm, enter 2.50.

  5. Perform the test

    Select Interaction only if the defined interaction occurred. Otherwise select No interaction.

  6. Continue or review

    If the app pauses at a boundary, save the data and review the setup instead of forcing the run onward.

Three gap terms that must not be mixed

Internal targetThe ideal next location before physical restrictions.
Requested gapThe reachable two-decimal setting to build.
Measured gapThe actual one-time reading used in the fit.
Example:

Internal target 2.47 mm → app requests 2.50 mm → completed setup measures 2.52 mm. The outcome is associated with 2.52 mm.

Read your results

A result may be calculated, unfinished, or paused for review. None of these screens changes a physical outcome that you entered.

Main locationMiddle gap

Evidence strength95% range

Uncertainty in the fitted estimate, not a reliability request.

Calculated result

Both outcomes were observed closely enough for the program to fit a curve. Read the middle gap, overall variation, and then their confidence ranges. The probability chart must fall as the gap increases.

Unfinished result

The completed tests did not show both outcomes closely enough to fit the curve. The data can still be saved. No substitute number is invented.

Paused for review

The outcomes conflict with the expected direction at a boundary, or no different useful reachable gap remains. A pause is not a failed article and not automatically a software failure.

Chance at one gap

The result window can estimate the chance of Interaction or No interaction at a selected gap. It shows the best fitted chance and a more cautious minimum supported by the data.

How to read a confidence range

“Middle gap 5.39 mm; 95% range 4.49 to 6.53 mm” means the data support a middle somewhere in that range under the model. It does not mean an article has a 95% chance of Interaction at 5.39 mm.

Why nine simulation cases had no fitted curve

Problem guide

The app asks for the same gap again

A useful repeat uses a new independent article and newly built setup. If every request remains stuck, save the record and note the test number and gap.

The requested gap cannot be built

Do not silently substitute another setting. Cancel before recording an outcome, then restart using the correct regular step or a confirmed gap list.

The measured gap differs from the request

Enter the actual measured value. The request guides construction; the measurement describes what was physically tested.

A confidence boundary is missing

The evidence did not establish that edge inside the permitted range. The screen says the boundary was not established instead of showing an impossible physical setting.

Nothing opens after the last test

Keep MATLAB open and read the Command Window message. Record the complete message and preserve the test data. V1.14 includes a check for the result-window naming problem found during release review.

Known physical limitation

The approximate 0.015 mm foil thickness does not prove that every 0.015 mm change—or even every 0.05 mm change—can be built consistently. Select a usable step only after confirming the setup.
