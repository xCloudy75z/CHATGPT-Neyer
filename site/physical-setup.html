Physical spacers and reachable gaps

Build only a confirmed reachable setting.

The requested gap is a construction instruction. Measure the completed build once and use that actual measured gap without treating provisional observations as a universal rule.

Foil is not a usable-step claim

Approximately 0.015 mm foil describes a component that was observed for construction. It does not prove a 0.015 mm usable test step, and it does not prove that every foil-and-spacer combination can be built or measured reliably.

The printed-spacer observations are provisional construction information. They help plan measurements; they are not proof of an exact spacer size or a general usable-gap rule.

Remaining physical confirmation

Final reachable combinations still depend on your confirmation measurements. If a request cannot be built as measured, select a confirmed setting or pause for review.

Measure each new build once

  1. Build the requested reachable setting, displayed with two decimal places.
  2. Take one reading of that completed build.
  3. Enter that measured gap; its entered precision is kept and it is used as the fitted gap.
  4. Use a newly built setup for the next destructive test.
