Project objective and scope

The objective was to audit the MATLAB Neyer implementation without altering its original file, reproduce its reference-table behaviour, separate real algorithm discrepancies from deliberate engineering choices, and then build a physically usable gap-test version. The method learns two quantities from destructive Go/No-Go tests. The middle gap is where interaction is about 50%. The transition width describes how quickly the response changes around that middle.

Stage 1

Search outward, then close the response bracket until its width reaches one guessed transition width.

Stage 2

Choose informative reachable gaps. Reduce the working width by 0.8 after each test until outcomes overlap.

Stage 3

Fit the middle and width, then choose later tests by D-optimal information.

Description of the original V1.8 tool

The preserved V1.8 Live Script reproduced Neyer's published Table 1 and provided a working three-stage sensitivity test. Its core probit maximum-likelihood calculation and D-optimal information determinant agreed with the method in principle. However, reproducing one published sequence did not exercise every decision branch. Several choicesâ€”especially the 1.5 sigma Stage-2 transitionâ€”were reconstruction choices rather than rules established by the paper.

How the audit was performed

  1. Preserved V1.8 and recorded its SHA-256 fingerprint.
  2. Created regression tests for the published reference-table sequence before changing behaviour.
  3. Compared Stage 1, both parts of Stage 2, maximum-likelihood fitting, D-optimal selection, bounds, rounding, and stopping logic with the documented Neyer process.
  4. Added focused tests for every corrected decision branch.

Physical test workflow

TermMeaningHow V1.9 uses it
Internal targetThe mathematical best next point.Kept at full precision for audit history.

Measured meanThe average of 4 or 5 readings taken on the newly built spacer setup.Used at its available precision as the statistical gap.

Every destructive test uses a new spacer build. The operator measures that unchanged build four or five times before testing it. Repeated readings describe measurement variation. They do not remove build-to-build variation, so the simulation includes both effects.

Boundary and stopping logic

The permitted study range defaults to 0â€“10 mm for this gap setup. A surprising no-interaction result at 0 mm, or interaction at 10 mm, receives one confirmation test at the same boundary. If the contradiction repeats, V1.9 pauses for review and preserves the run. It does not label the experiment a statistical failure.

Confidence limits outside 0â€“10 mm remain in the scientific record as raw mathematical results, but the interface does not present them as buildable settings.

MATLAB interface

How to operate V1.9

  1. Open Neyer_Gap_Test_v1_9.mlx in MATLAB R2022b.
  2. Run the Live Script. The Neyer Gap Test menu opens.
  3. Use Run a Demo (verify) first. It should show 5.3922 mm and 1.0412 mm.
  4. Select Run a Test, enter the 0â€“10 mm study range, guessed transition width, test count, unit, usable gap step, and approximate foil thickness.
  5. For each two-decimal build request, build a new spacer setup, measure it four or five times, enter all readings, then record Interaction or No interaction.
  6. Save the final CSV and HTML results from the results window.

Accepted inputs: finite numeric range values with maximum above minimum; positive guessed width; a whole-number test count; a short unit label; a positive usable step expressed in whole hundredths; and a positive foil thickness. The current provisional entries are 0.05 mm and 0.015 mm respectively.

Where result data are saved

The tool does not use a hidden fixed folder. The operator selects a folder and base name in the save window. Before writing, the app displays the complete intended paths for both outputs:

  • <selected folder>\<chosen name>.csv â€” complete test data.
  • <selected folder>\<chosen name>.html â€” self-contained result report and chart.

If either file already exists, the app writes neither file and asks the operator to choose another name. This prevents silent loss of an earlier test.

Known limits and operator decisions

  • The provisional 0.05 mm usable resolution still needs repeated complete-build confirmation.
  • One foil sheet is approximately 0.015 mm, but complete assemblies have not demonstrated 0.015 mm repeatable control.
  • The method estimates population response. It cannot remove unknown spacer construction bias or measurement calibration bias.
  • Extreme-data MLE convergence deserves a separate deep numerical study if this tool becomes a safety-critical qualification method.
  • Four or five readings describe one newly built spacer; destructive tests still introduce build-to-build variation.
