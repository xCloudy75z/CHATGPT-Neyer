# Application

The final operator file is [`../delivery/Neyer_Gap_Test_v1_10.mlx`](../delivery/Neyer_Gap_Test_v1_10.mlx). It is standalone and tested with MATLAB R2022b.

The `source/` folder contains the same application as readable MATLAB functions for review and testing. A normal operator does not need that folder, an executable, an internet connection, or an add-on package to run the `.mlx`.
